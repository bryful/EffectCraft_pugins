# Fs-ColorChange

EffectCraft デスクトップ用の色置換プラグインです。**Fs** カテゴリーから適用でき、最大16組のRGBを一度に置き換えます。

1. **Effect → Install Effect Plug-in…** で `Fs-ColorChange.wasm` をインストールします。
2. レイヤーに **Fs → Fs-ColorChange** を適用し、**Effect Controls** で編集します。

| パラメーター | 動作 |
| --- | --- |
| Tolerance (%) | 初期値0%。各RGBチャンネルの差が指定範囲内の色を置換します。スライダーは0〜20%、数値欄は0〜50%。 |
| Enable Color Pair 1〜16 | 色の組を個別に有効にします。初期状態では1組目のみ有効です。 |
| Source Color / Replacement Color 1〜16 | 各組の元の色と置換後の色をカラーピッカーで指定します。 |

判定は8ビットに丸めたRGBで行います。複数の組に一致した場合は番号が小さい組を使い、元のアルファを保ちます。置換色は8ビットに丸めずEffectCraftへ渡し、プロジェクトの8／16／32 bpcで描画します。

旧版のプロジェクトでは、1〜16組目の色設定を引き継ぎます。旧版の色数はチェックボックスに変換されないため、使用する組を個別に有効にしてください。既存のエフェクトには旧パラメーターも表示されます。
